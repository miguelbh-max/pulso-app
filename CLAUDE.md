# Pulso
App de entrenamiento en un solo archivo (index.html), publicada desde la rama main.

## Flujo de trabajo
- Cada cambio que pida el usuario se debe publicar automáticamente: commit, subir la rama, abrir un pull request contra main y fusionarlo (squash) sin pedir confirmación.
- Si el pull request anterior ya se fusionó, abrir uno nuevo.
- Antes de fusionar, probar el cambio en el navegador y revisar que no haya errores.
- Responder al usuario en español.
